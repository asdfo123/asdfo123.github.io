视频模型作为渲染器

Video Models as Generative Renderers

视频模型正在从"自己决定画什么"，变成"按外部给定的规格去画"。内容的决定权沿一架规格阶梯一步步移出模型：先是文本，再是参考图、多种参考的组合，最后是引擎、程序或仿真器算出的逐帧结构；视频模型负责忠实地画出来。

01

主张与定义

写进摘要、引言和第 2 章的那几句。

主张（建议措辞，待拍板 A）
内容的决定权沿规格阶梯移到模型外面（LLM、参考素材、程序、仿真器），视频模型的智能从"决定内容"转向"忠实执行规格"。"理解支配生成"的含义是：生成效果的上限，越来越取决于模型能否读懂规格，而不是它自己想象什么。

按因素的操作性定义

把视频要决定的内容拆成 8 个因素，分成两组。某个因素在生成之前已在模型外部以显式形式确定，就说模型在这个因素上被当作渲染器。这样"只给身份图算不算渲染器"就有了答案：它渲染身份和外观，其余因素自己生成。

外观规格：谁、长什么样、听起来怎样

阶梯的三个维度 v0.4

覆盖

外部规格确定了哪些因素，也就是上面 8 个里的哪几个。

精度

确定得多准：文字描述 < 参考示例（输出要像它，但不逐帧对齐）< 逐帧对齐（白膜、骨架、框、轨迹）。

主导权

谁持有规格、模型能不能推翻它。文本和参考是模型自行解释、也可能不听的输入；第 3 档由外部系统持有状态，渲染器只保留视觉记忆。

只看覆盖分不开第 2、3 档：多种参考的组合也能提到每个因素，但没有一个是逐帧对齐的，也没有外部状态撑着。对应 Overleaf 第 2 章 §2.1–2.3；"模型边界"的判定规则见 §08 拍板 B。

在 v3 基础上的增补

  
Agent 在整理 Overleaf 时补进去的分析，均已写入对应章节；需要组里认可后再定稿。前五条是 v0.4（11/5）新增。

  

    
规格阶梯（v0.4）
用覆盖、精度、主导权三个维度定义四档。只看"完备度"分不开第 2、3 档，精度和主导权才分得开；这样阶梯可以量化，也和"世界状态 vs 视觉记忆"打通。

    
第 0 档：文本规格
从 caption 与提示词改写讲起，补上"为什么外移"：DALL·E 3 重写 caption 并在推理时扩写提示词；VPO、Prompt-A-Video 训练改写器；VC4VG 显示 caption 质量与生成质量强相关。四篇已核实入库。

    
阶梯不是历史
几何谱系来自图形学（vid2vid → Generative Rendering → Cosmos-Transfer → MG4），不经过第 1–2 档；到第 3 档参考退为外观槽，22 个结构渲染器里 7 个复用 H3 参考通道。

    
按条件分档，不按应用
音频驱动的数字人属第 2 档（参考图 + 音频）；只有外部面部或身体参数驱动的才算第 3 档。第 7 章据此只写一段实时数字人。

    
结论改成论证
每次升档都由下一档的失败逼出；第 3 档分工为什么稳定；三个可观察的回退信号（端到端模型的长时程状态、无结构控制的精度、构造规格的成本）；开放问题按"卡在哪一档"重排。

    
定义改为按因素判断
解决"只给身份图算不算渲染器"的二元困境；阶梯的"覆盖"维度有了度量：外部确定了哪些因素。

    
主张措辞与模型边界
建议主张改为"智能从决定内容转向执行规格"，化解与第 5 章"渲染侧也在加理解"的张力；给出模型边界规则（拍板 A、B）。

    
汇合说法收窄，并给数据
v3 写"5 个结构渲染器都建在 H3 参考通道"属实，但补上全貌：22 个里 7 个走 H3，其余走输入融合、分支、交叉注意力；可能有开源底座的路径依赖。

    
世界状态 ≠ 视觉记忆
渲染器不持有权威状态，但要维护"长什么样"的记忆；三个架构证据：Matrix-Game 4.0 历史缓存不含控制信号、Wizard 换身份时屏蔽旧身份 token、PWM 身份槽位。

    
蒸馏会侵蚀控制
SolarRenderer：通用四步加速 LoRA 会偏移控制，普通分布匹配把学生拉回模糊老师（Elo 1024 → 820）；沿结构条件外推老师后 1156。渲染器特有的训练坑。

    
延迟 ≠ 吞吐
Magpie 32.2 FPS 但按键到画面约 1.55 s；Matrix-Game 4.0 4 帧一块，112 ms。块时长是延迟下界，帧率再高也压不掉；评测要分开报。

    
按因素评测有外部佐证
OmniVBench 按"保留、解耦、路由"逐因素评测参考，和条件决定矩阵同构；"相似度奖励照搬"在各档都成立（RefAlign 消融、结构侧边缘 F1 偏爱描边）。

    
竞品表补三篇
Agentic Visual Generation（2609.06758）、Simulating the Visual World（2511.08585，作反方）、From Pixels to States（2607.14076）。2610.40191 §4.3 已全文读过，重叠集中在结构侧系统层面。

    
建议加一个小实验
在同一底座上比较"去噪窗口"和"对齐 vs 输入 DINOv3"两组解法，给出第 1–2 档与第 3 档第一次同协议比较。综述越来越多，有实验的分析性贡献更站得住。
